# Source selection and quote readouts

The UI accepts `/meta` instruments only when the producer's full descriptor matches the stable source identity (exchange, market, symbol, native symbol, category, contract kind, quote and settlement). The advertised `exchanges[].markets` and `exchanges[].symbols` must also contain the pair; no Cartesian product is assumed. The two new Binance keys (`spot_usdc`, `usdm_usdc`) are *never* made available by an old, stale, malformed or failed metadata response. Existing source keys remain in the legacy fallback; Coinbase INTX `usdm` and Bybit are retired. Saved old preferences retain the same source interpretation, with the existing explicit Coinbase INTX→DRB migration and discontinuity note.

`spot` and `spot_usdc` are spot-v1; the USDC spot client sends the series selector explicitly and refuses a missing response series. Legacy spot can still accept an omitted response series. Contracts use contracts-drb-v1. New source history is independent and an empty selection says “no stored history yet,” not zero/complete coverage. HTTP request generations and WS connection generations isolate late source frames and indicator state; explicit contradictory response identity is rejected. Legacy base envelopes contain a series but generally do **not** echo exchange/market/symbol: the client cannot prove a server-side same-series wrong-quote response from its envelope alone, so server selection/routing remains authoritative. Cross-venue combinations never leave the browser.

Source readouts use USDT for Binance `spot`/`usdm`, USDC for `spot_usdc`/`usdm_usdc` and Coinbase DRB, and USD for Coinbase `spot` and Binance inverse `coinm`. Aggregated CVD/flow are **nominal USD/USDT/USDC quote turnover without FX conversion**, not converted USD. `cvd_usdt`, `delta_usdt`, and other legacy wire fields keep their ABI names. No indicator computation or renderer math changes here.
